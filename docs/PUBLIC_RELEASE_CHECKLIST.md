# Public release checklist

Preview 8 is prepared in a separate private release-candidate repository. The original private repository and older releases stay intact. Publishing this candidate will expose only its own retained history and attached assets, not those of the original repo.

## Release checks

- Check the final source and Windows archive use the same version and notices. Do not replace earlier release bytes.
- Run the core and full suites; report skipped external checks honestly. Observe the Windows Node 22 and 24 workflow on GitHub.
- Launch the extracted Windows command normally and confirm the default browser loads the matching creator screen. Test review, saved work, restart and update in an isolated profile.
- Review source, embedded packages and candidate history for private material. Pattern scans do not inspect every image or video pixel.
- Keep private tester projects and chat exports out. The independent user’s successful build is enough; their project is not marketing material.
- Confirm the README download, issue forms and COO contact are correct. No test email or response-time promise is required.
- Keep [the licence schedule](../LICENSE), [creator rights](../CREATOR_RIGHTS.md) and historical exceptions intact. The owner has approved the terms and company launcher inclusion; no separate contributor-permission blocker remains. Specialist review is recommended, not claimed.

## Owner publication

The owner decides when to make the candidate public. If its repository name changes, update the current download and help links; keep old private history private. Do not force-push or overwrite the original repo to accomplish this.

After publication, check the release download and issue forms while signed out. Review GitHub’s visibility consequences before confirming. The COO email is the private security-reporting route; do not advertise GitHub private vulnerability reporting unless enabled and checked.

No store, payment integration, new example or additional research programme is required for this preview.
