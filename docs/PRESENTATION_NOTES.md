# Presentation notes · 6 October 2026

The owner asked for inspiration from Moltbot, Hermes and Codex. We inspected the current official repositories: [OpenClaw](https://github.com/openclaw/openclaw), [Hermes Agent](https://github.com/NousResearch/hermes-agent) and [OpenAI Codex](https://github.com/openai/codex).

The useful presentation patterns were a clear first sentence, a visible route to getting started, concrete examples and deeper technical documentation below the introduction. Ditto uses those general patterns with its own wording, artwork, screenshots and product promise. No code, brand artwork, testimonials or popularity figures were copied from those projects.

Our audience is not assumed to know terminals, package managers or model infrastructure. The main route is a Windows ZIP, a double-click launcher, ordinary-language instructions and actual screens. Developer commands remain available lower down.

The primary action is making a personal workspace. Example apps are supporting stories. The future I’m-Store is clearly separated from the working preview. Safety limits appear near the first download, not hidden at the bottom.
