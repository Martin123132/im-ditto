# I’m-Ditto preview 8 release readiness

Prepared on 7 October 2026 in a separate private candidate, preserving the original repository and preview 5–7 archives. Public visibility remains the owner’s decision.

## Release scope

Preview 8 contains the approved Core/MIT-starter licence split, starter-notice preservation, support routes, the existing corrected launcher and optional Bridge clock display. It starts a fresh Git history rather than publishing the previous private commits or their author email. Earlier grants and inherited notices remain unchanged.

Source version, health response, footer and offline start page are aligned to preview 8. The Windows ZIP must be built from the final candidate commit, with an accompanying checksum. Existing archives must not be replaced.

## Validation status

The immediately preceding source passed 52 full-suite tests with one external-Bridge skip, and 51 core tests with the same skip. Those are prior local results, not final preview 8 or GitHub CI claims.

Final candidate tests, normal Windows launch, archive checks and GitHub workflow results will be recorded before the release is handed over. The same-PC portable test is not a clean Windows installation study.

## Privacy and trust

The candidate excludes user profiles, private tester material and prior Git history. Its text/package scan looks for recognised secrets and blocked paths; it is not security certification. Existing tutorial media requires a separate visual check.

Generated apps are trusted native code, not OS-sandboxed. Hashes do not authenticate publishers. The COO contact is the chosen private reporting route; no mailbox delivery or response-time guarantee is claimed. The custom licence terms are owner-approved, not solicitor-reviewed.
