# I’m-Ditto · Preview 6

Private Windows x64 preview for review and a friend’s first independent try-out.
The main job is still **make your own I’m**, not install our examples.

## Try it

Download **Im-Ditto-0.1.0-preview.6-Windows-x64.zip** from this private release.
Extract the whole folder and open **Launch Im-Ditto.cmd**. Node is included;
there is no installer or new subscription. Start at **Make my I’m** and choose
your own small useful job. [Short try-out guide](../FRIEND_TRIAL.md).

An existing source checkout can pull `main` and run `npm start` with Node 22+.
No `npm install` is required. Keep saved profiles and workspaces; do not overwrite
them with a download. Preview 5 remains available unchanged.

## What changed

- Optional compact Bridge reply-clock display: separate chats, remaining time,
  wrap-up, finished state, last contact and checkpoint timestamps.
- Correct per-message guidance: a new reply gets a new period; tools and
  reconnects inside that reply do not restart it. No manual chat unlock.
- Private handover notes stay in Bridge. The display cannot pause work, change
  permissions, extend a clock or finish a reply on the agent’s behalf.
- Older, closed or incompatible Bridge is reported honestly and does not block
  Ditto. Local Codex and normal app controls remain available.
- Friend-test guide, integration source and review notes included in the repo.

The optional clock needs a compatible updated PC Bridge. This release does not
install or update Bridge, Chaff or I’m Accessibility. Accessibility is not needed.

## Checks and limits

- 43/43 Ditto tests with the separate inspected Bridge module supplied;
  a source-only run skips that external integration test.
- 20/20 focused Bridge timer/transport checks and packaged clock UI passed.
- Portable fresh-profile check passed with the included Node and without global
  Node/FFmpeg on PATH, including saved-work restart and a creator fixture.
- Full Bridge desktop smoke still has the same Enable-access assertion failure
  in both the unchanged baseline and candidate; it is not counted as a pass.

These are local checks, not a clean-machine or independent-user result. Clock
activity is not proof the AI is thinking and cannot guarantee provider timeouts
never happen. Generated apps run as your Windows user, **not in an OS sandbox**.
Review unfamiliar code before installing it. The archive excludes personal
profiles, credentials and private chat notes. This remains a private prerelease,
not a public launch or I’m-Store.
