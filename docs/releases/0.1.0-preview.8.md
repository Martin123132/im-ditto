# I’m-Ditto preview 8

Make your own workspace with your connected AI, review what it builds, and use the same saved work together. This Windows x64 preview keeps creation as the starting point; examples are optional.

## What changed

- The designated creator starter is MIT licensed. New builds carry its licence and attribution through packaging, installation, updates and rollback. Your own additions can use your own terms.
- The host uses the company’s source-available Core licence. The file schedule preserves inherited, example and third-party terms; earlier grants remain unchanged. There is no compulsory store listing or royalty on independent app sales.
- Help, security-reporting guidance and issue forms now give a clear route to support. Security and commercial enquiries go to the company COO.
- Automated Windows source checks cover Node 22 and 24. The release checker inspects exported source, embedded packages, metadata, links and retained history for recognised credential patterns and private-data paths.
- The Windows default-browser launcher and optional read-only Bridge reply clocks are retained from preview 7. Ditto does not install, update or unpause Bridge.

## Download and start

Download **Im-Ditto-0.1.0-preview.8-Windows-x64.zip**, extract the whole ZIP, and open **Launch Im-Ditto.cmd**. Node is included; FFmpeg is only needed for the optional Studio example and is not bundled. Open **START_HERE.html** for the offline guide and connection video.

Keep existing profiles and saved work. Do not extract a download over your only copy of a workspace. Back it up first; the launcher uses the profile beside its own extracted folder.

## Boundaries

This is an early trusted-code preview, not an OS sandbox or a marketplace. Package hashes check bytes, not publisher identity or safety. AI access and billing remain with your chosen provider. Tests do not certify arbitrary generated apps. See [review and test scope](../../REVIEW.md), [creator rights](../../CREATOR_RIGHTS.md) and [security boundaries](../../DITTO_SECURITY.md).

This release starts a clean source history. Older private repositories, archives and their licence grants are preserved separately, not rewritten or revoked.
