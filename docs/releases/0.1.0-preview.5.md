# I’m-Ditto · private creator preview 5

**Start with your own idea, not a catalogue.** This version puts Make my I’m first and explains the five-step path from a sentence to a personal workspace.

## Download and open

1. Download **Im-Ditto-0.1.0-preview.5-Windows-x64.zip** below.
2. Extract the ZIP into a new folder; do not overwrite an existing profile.
3. Open **START_HERE.html**, then double-click **Launch Im-Ditto.cmd**.
4. Start on **Make my I’m**, or use **How to Ditto → Walk me through making my own**.

The Node runtime is included. There is no installer, service or background update. Video Studio is optional and needs separately available FFmpeg/FFprobe; the host and board-game example do not.

## Before running an I’m

Generated apps run as your Windows user, **not inside an OS sandbox**. Review unfamiliar code. File hashes do not authenticate its publisher. ChatGPT needs a working PC Bridge connection; local Codex needs access to the build folder. Your chosen AI provider's normal limits and charges apply.

This is a **private review prerelease**, not the public launch or an I’m-Store. Your existing PC Bridge and Chaff installations are not replaced. Nothing was published publicly.
