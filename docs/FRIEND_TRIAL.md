# Your first I’m — a short private try-out

**You do not need I’m Accessibility, a new subscription or either bundled example.**
Use your existing AI connection. This Windows preview runs trusted native code as
your Windows user; use harmless test data, not passwords or important originals.

1. Extract the entire supplied ZIP into a folder you control. Open
   **Launch Im-Ditto.cmd**. Keep the extracted folder; do not launch from inside the ZIP.
2. On **Make my I’m**, choose a small job you actually want help with. Your idea,
   not ours: something with a few useful controls and a saved or exported result.
3. Describe what goes in, what you want to change, and what should come out.
   Choose **Prepare my I’m** and copy the generated prompt into your connected AI.
   It must already have access to the new build folder. Do not paste credentials.
4. Let it build and test. If you use a compatible updated PC Bridge, Ditto's small
   **reply clock** panel shows its current reply period. Each new message starts
   a fresh period; reconnecting does not extend the same reply. The clock is optional:
   an older Bridge or local Codex still works without the display. No manual unlock.
5. Return to Ditto and **Check finished package**. Read the reported tests and
   limitations. A package check is not proof the app is safe; install only if you
   trust what was built. Start it from **My I’ms** and try your actual small job.
6. Save something, close the workspace normally, reopen it, and check your work
   is still there. Ask your AI for one small improvement if you have time.

## What we want to learn

Please try the first steps without a guided tour. If you need help, that is useful
feedback, not a failure on your part. Record the first point where you got stuck.

- What did you think Ditto would do when you first opened it?
- What did you choose to make, and did you get a useful result?
- Which wording, permission step or wait was confusing?
- Did your saved work survive reopening?
- If reply clocks were available, did they help? Were any states misleading?
- Would you use this again? What is the first thing you would change?

Screenshots and the exact error are enough. Please keep private chats, credentials,
connection URLs and personal files out of anything you send back. No recording or
automatic telemetry is required. This is an independent user trial, not a scored
benchmark and not a claim that every type of I’m already works.
