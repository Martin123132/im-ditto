START YOUR OWN

Tell us what you want to make.

Describe the inputs, useful controls and the output you want. Leave passwords and personal data out. Nothing is sent to an AI until you paste the prompt yourself.

Creates a separate editable starter. It does not build, install or run your finished I’m.

How does my AI get involved?

Use the AI you already have. A local Codex task needs access to the build folder. ChatGPT needs your existing PC Bridge connection and that folder shared through its owner controls. The generated prompt contains the exact paths and instructions.

If you have not connected ChatGPT yet, follow PC Bridge’s setup guide. You can describe your I’m now and return to the saved request later. No example app needs to be installed first. I’m-Ditto does not include a model or an AI subscription.

NOW BUILD IT TOGETHER

  1. Copy this prompt into your connected Bridge chat or local Codex task with access to the build folder.
  2. Work through the build with your AI. Ask it to show what works, report what it tested and explain anything unfinished. The starter is a tiny notes app; it must become the workspace you described.
  3. Return here when the package is ready. Check it, review the files and access, and install only when you trust it. Then use My I’ms → Start → Connect my AI.

Return after the AI finishes. Checking reads the package; it does not execute it or certify its quality. Installation requires your trust of the exact bytes.

Your work, access and preview boundaries
Your personal Bridge stays separate. Ditto does not silently update it or change its permissions. This app uses your existing AI connection; it does not put a model inside each I’m. Packages are native programs running as your Windows user, not an operating-system sandbox. Declared permissions are informative, and hashes check bytes—not author identity or safety. Removing an I’m keeps its projects and releases. The portable build includes Node; the optional Studio example needs FFmpeg/FFprobe.
