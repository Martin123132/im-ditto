# I’m-Ditto preview 8 review

Preview 8 is a Windows x64 creator-first release: describe a job, build with your connected AI, review the package, then use and improve your own workspace. The optional examples are not the product’s limits or required installations.

## Included

- A separate starter folder and tailored build prompt, exact-package review and deliberate installation.
- A five-step creation lesson, offline guide, connection video and real rehearsal-desk walkthrough.
- Shared human and AI state; finite commands; saved-data preservation across restart, update and rollback.
- The corrected Windows browser launcher and optional read-only Bridge reply clocks. Existing Bridge and Chaff installations remain separate.
- An MIT creator starter with notice-preservation tests, separate company Core terms, plain creator rights and support guidance.

The owner reports that an independent user built and used their own I’m. Their private project, screenshots and story are not distributed here. That experience does not establish success for every new user or Windows installation.

## Checks and evidence

[Release readiness](docs/RELEASE_READINESS.md) records the current candidate checks. [Release checks](docs/RELEASE_CHECKS.md) preserves dated earlier evidence and explains the required normal-launch check. A test marked skipped is not a pass; local checks are not a GitHub Actions result.

The walkthrough was built through ChatGPT and Bridge on the owner’s PC, with shared edits, a usable export, restart and an update preserving work. Read [the creation journey](docs/CREATOR_JOURNEY.md) for its actual scope. A starter smoke test is not further evidence of AI creating a novel app.

The included 4:40 video is the earlier setup/connection reference, not a recording of the latest creator screen. The separate three-minute creation-film source remains review material; it is not a finished MP4 download.

## Trust and licence boundaries

Generated apps run as the Windows user, not in an OS sandbox. Declared access is descriptive; a package hash checks bytes, not publisher identity or safety. Review unfamiliar code before running it.

ChatGPT requires a working PC Bridge connection and intended-folder access. Local Codex requires access to that folder but no Bridge tunnel. Ditto does not contain a model, grant access, or guarantee builds will succeed without repair.

The designated starter is MIT licensed; creators choose terms for their own additions. The host and company launcher use the source-available Core licence, with inherited and third-party exceptions. The owner approved this arrangement, including the COO contribution. Earlier grants remain unchanged. Custom terms have not been solicitor-reviewed. See [LICENSE](LICENSE) and [creator rights](CREATOR_RIGHTS.md).
