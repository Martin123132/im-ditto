# Bundled runtime notice

`LICENSE-node-v24.15.0.txt` is the unmodified official Node.js v24.15.0 license and bundled third-party notices downloaded from the Node.js distribution. It is included in portable builds alongside the runtime.

The current Windows x64 preview bundles Node v24.15.0. The builder copies the executing Node binary; use that matching runtime when reproducing this preview. No FFmpeg binary is distributed: Studio checks for FFmpeg and FFprobe on the owner's PATH.
